Add a 1024x1024 PNG image named `app_icon.png` here to be used as your Flutter launcher icon.

- For Android adaptive icons, you can also add a foreground PNG named `app_icon_foreground.png` and set `adaptive_icon_background` in `pubspec.yaml`.
- Recommended: PNG, 32-bit with alpha, 1024x1024.

How to generate icons:

1. Run `flutter pub get` to pick up the new dev_dependency.
2. Run `flutter pub run flutter_launcher_icons:main` to generate icons for Android and iOS.
